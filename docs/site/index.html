How it works

From impact to score

A hybrid pipeline: cheap image processing runs all the time, the neural network only wakes up when something moved.

Motion trigger

A frame difference on each camera notices that a dart landed – or that a hand is pulling darts.

Tip detection

A YOLO pose model (ONNX Runtime, CPU) finds the dart tip in every view; classic CV is the fallback.

Board mapping

Lens correction and a per-camera homography turn pixels into millimetres on the board plane.

Fusion

The three views vote: agreeing cameras first, then weighted by local resolution. Outliers are dropped.

Score & referee

Position → segment and ring. Unsure darts get a second, slower look before they count.

Playing

Built to be read from the oche

Big condensed numbers, clear turn state and a display mode for small screens – readable from three metres on a TV.

  • Automatic turn change when you pull your darts
  • Checkout route shown in green right in the empty dart fields, tuned to your favourite double
  • Two-tap correction via keypad or by tapping the board, bounce-outs included
  • Visit photos: camera images of every turn with the detected tip positions
  • Stadium caller with offline voice clips, sounds and celebration effects for 180s and checkouts
Statistics

Every dart, with coordinates

Each dart is stored with its board position, so every number can be recomputed at any time – and a lot more than averages is possible.

  • X01: 3-dart and first-9 average, checkout rate, best leg, 60+/100+/140+/180
  • Cricket: marks per round; win/loss and head-to-head between profiles
  • Heatmap and grouping from detected positions, hit rate per double
  • Aim deviation: which way and how far you miss the field you aimed at
  • Trends for every training mode, form curve, best and weakest games, achievements
  • Export to CSV/JSON, daily database backups with restore
Profiles & training

For the whole household

Any number of local profiles plus guests. Photos from the phone camera or a gallery of 16 characters, an optional PIN against accidental edits.

  • Training plans: four built-in plans of five sessions, goals per drill, results recorded automatically
  • Bots with an adjustable average – or a personal bot that throws like you
  • Handicap: own start score per player so kids can keep up
  • Teams sharing a score, and local tournaments (knockout with byes or round robin)

Arcade

The board is the game world

The cameras know exactly where each dart landed, so games can use the real position – not only the segment.

Monster hunt

Monsters sit on spots of the board. Hit close enough and they are caught; missed ones grow – easier to hit, but worth fewer points. Some wander every visit, the last round counts double.

X01 Voltage

Regular X01 rules, arcade looks: remaining scores drain like batteries, darts appear on a neon board at their real position, big scores strike lightning.

Under the hood

Made for a real living room

Guided calibration

Click reference points per camera, get a board overlay to check it, lens calibration with a printable chessboard. Bumped cameras are re-aligned automatically.

Referee

Low-confidence darts are re-checked before scoring; any recorded dart can be re-evaluated later. Confirmed darts become training data.

Any screen

Responsive web UI for TV, desktop, tablet and phone, installable as an app. A QR code on the big screen opens dartscore on your phone.

Diagnostics

CPU and memory, frame rate per camera, detection timing and the latest darts – so you see at once why something was missed.

Private by design

SQLite on your own machine, photos resized and stripped of metadata. Works without internet after installation.

Old hardware welcome

Runs on a 2012 Mac mini without AVX2. The model only runs after the motion trigger and on the board region; Linux first, designed for macOS, Windows and Raspberry Pi 5 as well.

Setup

What you need

Hardware

A steel-tip board, three USB cameras mounted about 120° apart close to the board plane (an Autodarts-compatible OV9732 set works), and an LED ring for even light.

Any small PC in your network – the reference machine is a Mac mini from 2012 with Debian 12. Displays are simply browsers.

Software

Python 3.12 via uv, Node.js ≥ 20 for building the UI. FastAPI + SQLite in the backend, React + TypeScript in the browser.

A systemd unit is included for running dartscore as a service.

# install dependencies and create a config
$ make install
$ cp config.example.toml config.toml

# build the UI once, then start the server
$ cd frontend && npm run build && cd ..
$ make dev-backend

# open http://<host>:8000 on the TV, tablet or phone

Details are in the README and the hardware notes. No cameras yet? Set source = "synthetic" and play with manual input.
